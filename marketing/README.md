# مواد دورلي التسويقية

| المجلد | المحتوى |
|---|---|
| `رسائل-التعريف.txt` | رسالة واتساب قصيرة، منشور فيسبوك كامل بالروابط، رسالة استقطاب مندوبين، ورد جاهز للزبون |
| `images/` | 7 منشورات (1080×1350 — فيسبوك/إنستغرام) و2 ستوري (1080×1920 — حالة واتساب/ستوري) |
| `video/` | فيديو تعريفي عمودي 1080×1920، 45 ثانية، بدون صوت (أضف موسيقى من محرر تيك توك/إنستغرام) |
| `source/` | ملفات التصميم المصدرية لإعادة التوليد بعد أي تعديل |

## إعادة التوليد بعد التعديل
التصاميم صفحات HTML (`source/ads.html` و`source/video.html`) تُرسم بمتصفح Chrome المثبّت:

```bash
# مرة واحدة: أدوات الرسم في مجلد منفصل
mkdir tools && cd tools && npm init -y && npm i puppeteer-core@23 ffmpeg-static@5 && cd ..
# الصور (يعيد التقاط شاشات الموقع الحي أيضاً)
node marketing/source/render-ads.mjs tools marketing/images
# الفيديو
node marketing/source/render-video.mjs tools marketing/video/دورلي-فيديو-تعريفي.mp4
```

الأسعار والضمانات في التصاميم مأخوذة من الموقع (الباقات 20/40/70 د.ل، الدفع عند الاستلام، ضمان استرداد رسوم الخدمة).
أرقام عرض السعر في الفيديو وصورة التتبع (420 + 30 = 450 د.ل، الرقم DW-2026-1234) **أمثلة توضيحية** وليست طلباً حقيقياً.
